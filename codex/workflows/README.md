# Fluxos de trabalho

Documente aqui procedimentos recorrentes que precisam de uma sequência previsível, como preparar uma release, atualizar conteúdo de deploy ou revisar uma migration.

Um bom fluxo informa os pré-requisitos, os arquivos envolvidos, as etapas, como revisar o resultado e quais ações externas exigem solicitação explícita. Mantenha instruções de uso pontual fora daqui.
