# Biblioteca de trabalho do Codex

Use esta pasta para manter contexto e instruções reutilizáveis deste projeto. O índice principal fica em [`../codex.md`](../codex.md).

## Organização

- `context/`: informações estáveis sobre produto, arquitetura e decisões.
- `rules/`: regras de trabalho específicas do repositório.
- `skills/`: procedimentos especializados, cada um documentado em seu próprio `SKILL.md`.
- `workflows/`: passos de tarefas recorrentes que não precisam ser uma skill.
- `templates/`: modelos para criar novos materiais consistentes.

Prefira arquivos curtos, com escopo claro e exemplos concretos. Atualize o índice em `codex.md` quando adicionar uma instrução que deva ser consultada no início de uma tarefa.
