# Skills do projeto

Guarde aqui instruções especializadas e reutilizáveis. Cada skill deve ficar em uma pasta própria com um `SKILL.md` que explique quando usar, os passos e o formato esperado do resultado.

Use [`../templates/SKILL_TEMPLATE.md`](../templates/SKILL_TEMPLATE.md) como ponto de partida. Depois de criar uma skill, inclua uma linha abaixo e atualize `codex.md` caso ela deva ser consultada em todas as tarefas.
